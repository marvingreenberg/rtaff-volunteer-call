volunteer-call mockups

Three aesthetic directions applied to the volunteer-response and assignment+task views. Each file has a working density toggle (top right) so the compact / standard / large deltas are visible, not just described. Mobile preview is rendered alongside desktop in each file.

  • A · Editorial-refined
    Print-weekly feel. Hairline dividers replace card borders. Display font swapped to Fraunces; body to Söhne-alike. Numerics get tabular tracking. Structure comes from spacing.
  • B · Soft-modular recommended
    Linear/Notion-leaning. Larger radii (12px), layered surfaces with subtle gradient page background, tinted card heads using brand colors at low opacity. Density tiers actually restructure card grouping (large = each task its own card, compact = single table).
  • C · Architectural
    Vercel/Railway-leaning. Sharp 4px radii, JetBrains Mono for numerics and timestamps, confident grid with thin guide lines, status pills with leading colored dot. Numbers feel important.
